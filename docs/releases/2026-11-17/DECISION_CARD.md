# 亚字段血缘：交付决策卡（2026-11-17）

**建议先批准只读诊断摘要。该方案尚未获批，也未实装。** 本卡随本次交付材料提供，所述验收范围以 [交付说明](./DELIVERY.md) 和 [评估记录](./EVALUATION.md) 为准。

1. **先做只读诊断摘要。** 从现有本地证据包汇总已观测使用、携带和未决断点，逐项回到当次响应、源码位置和保护范围。最小验收：拿掉一条中间证据，摘要显示「未决」，仍能追溯其余已证事实；原始响应不变。摘要只帮助排查，不补图、不自动解包、不扩大覆盖或删键候选。
2. **补齐原件后验证一条真实链。** 需要三类证据：① 生效的视图定义及投影、过滤和底层分区映射；② 中间表实际 DDL（列序、类型、分区）；③ 同一业务日一个真实的 19 点前小时，成功写入与实际扫描同一物理表不可变提交或快照的证据，包含两端发布 SQL、渲染实参、运行标识和完整分区。字段图可定位取证目标；同表名、同名分区或计划扫描不能证明读到了同一批数据。三项仍缺。到件先验来源、版本与字节，再逐边核实实际扫描和字段原样透传；独立验证前结论止于局部。
3. **启发式暂不参与剪枝。** 共现、频次和规则分数只用于安排人工复核。未观察到消费不等于无依赖，局部值传播不证明行集等价，分别可省也不代表能一起省。待固定计划、输入适用范围和受保护行为都有可复核证据，再重议。若暂不决定，继续用现有检查器及证据导出，按既有证据修缺陷。

**三类计分与测量口径。**

- **冻结静态回放：** 288 个候选、210 份唯一内容，和旧清单重叠 31 个成员（17 份唯一内容）。214/288 整解析、56 部分恢复、4 失败、14 超限；274 份响应中 258 份有语义未知。四个失败成员对应两份仅含 Shell 输出命令、无 SQL 正文的内容，未执行，不归因于 SQL 方言，原分母保留。固定 Hive 假设、无调用方 schema 的配对独验中，两版 274 份静态响应逐字节相同。首跑逐项 P95 为 432.173 ms，含分析和 JSON 序列化，不含预检和写盘；命令墙钟 37.253 秒另含这些操作。此为静态覆盖和一致性，不是吞吐、严格盲测或准确率。
