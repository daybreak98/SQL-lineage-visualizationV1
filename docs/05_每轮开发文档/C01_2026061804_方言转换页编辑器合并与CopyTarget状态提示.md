# 方言转换页面编辑器合并与 Copy Target 状态提示

日期：2026-06-18 04:00
改动原因：方言转换页存在 Compare / Edit Target 双模式，Compare 模式锁定源编辑器导致体验割裂，且两模式功能重叠增加认知负担；同时 Copy Target 按钮缺少转换后状态反馈，用户无法感知目标 SQL 是否已被手动修改。

## 1. 改动概述

### 1.1 编辑器合并

**改动前**
- 工具栏有 `Compare` / `Edit Target` 两个切换按钮
- Compare 模式：使用 Monaco DiffEditor，源侧 `originalEditable: false`，目标侧 `readOnly: false`
- Edit Target 模式：两个独立 Monaco Editor，左右均可编辑，支持拖拽分隔条

**改动后**
- 移除 `DiffMode` 类型和 `diffMode` 状态
- 移除工具栏的 Compare / Edit Target 切换按钮
- 默认视图：左右两个独立 Monaco Editor，均可编辑，保留拖拽分隔条
- 新增 `Show Diff` 切换按钮：点击后在编辑器区域叠加 Monaco DiffEditor，再次点击关闭叠加层
- Diff 叠加层右上角提供 `Close Diff` 按钮

### 1.2 Copy Target 状态提示

**改动前**
- Copy Target 按钮始终为默认灰色，仅在 `targetSql` 为空时 disabled

**改动后**
- 状态规则：
  - 未执行过转换：灰色（disabled 当 targetSql 为空）
  - 转换成功后：浅绿色（`pill.trusted` 同色系），表示"结果是干净的，可直接复制"
  - 用户编辑目标 SQL 后：恢复灰色，表示"结果已被修改"
- 实现：复用 `isTargetDirty` 状态，转换完成时置为 `false`，目标编辑器 `onChange` 时置为 `true`
- 样式：新增 `.btn-copy-clean` 类，背景 `#ECFDF5`，边框 `#BBF7D0`，文字 `#047857`

## 3. 详细改动

### 3.1 DialectConvertPage.tsx

#### 移除
- `type DiffMode = 'split' | 'target_only'`
- `const [diffMode, setDiffMode] = useState<DiffMode>('split')`
- 工具栏中 `view-toggle` 区块（Compare / Edit Target 按钮）

#### 新增
- `const [showDiff, setShowDiff] = useState(false)`
- 工具栏新增 `Show Diff` 按钮（`tool-btn` 样式，active 时高亮）
- 编辑器区域结构：
  ```
  <div className="convert-workspace">
    {/* 左侧源编辑器（始终存在） */}
    <section className="editor convert-source">...</section>
    
    {/* 分隔条（始终存在） */}
    <div className="convert-splitter-zone">...</div>
    
    {/* 右侧目标编辑器（始终存在） */}
    <section className="convert-target-panel">...</section>
    
    {/* Diff 叠加层（条件渲染） */}
    {showDiff && (
      <div className="diff-overlay">
        <div className="diff-overlay-head">
          <span>Diff Preview</span>
          <button onClick={() => setShowDiff(false)}>Close Diff</button>
        </div>
        <DiffEditor ... />
      </div>
    )}
  </div>
  ```

#### Copy Target 按钮
- 原逻辑：`<button className="btn-primary secondary" onClick={onCopyTarget} disabled={!targetSql.trim()}>Copy Target</button>`
- 新逻辑：
  ```tsx
  <button
    className={cx('btn-copy', !isTargetDirty && targetSql.trim() && 'btn-copy-clean')}
    onClick={onCopyTarget}
    disabled={!targetSql.trim()}
  >
    Copy Target
  </button>
  ```
- 该按钮同时出现在目标编辑器 panel-head 中（原 convert-head-actions 位置）
